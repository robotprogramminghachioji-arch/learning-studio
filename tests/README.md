# ブラウザ回帰テスト

Node.js 20以上とChromiumを使用します。アプリ自体にはnpm依存もビルドも不要です。npm依存はテスト専用です。

```sh
npm ci
# Chromiumが未導入の場合
npx playwright install chromium
npm test
```

Linuxでは `/usr/bin/chromium` があれば使用し、それ以外ではPlaywrightのChromiumを使用します。別の実行ファイルを使う場合は `CHROMIUM_PATH` で指定できます。現在のクラウド環境でnpmキャッシュに書き込めない場合は `npm --cache /tmp/learning-studio-npm-cache ci` を使えます。

テストは一時的なHTTPサーバーを起動し、実際の `index.html`、アプリのJavaScript/CSS、教材画像、sandbox付きプレビューをChromiumで操作します。Firebase SDKの通信境界のみを代替し、ログイン済み生徒・先生と保存成功・失敗・応答遅延を再現します。本番Firebaseへの書き込みやアカウント作成は行いません。

確認項目：ページ送りの画面上部固定（ページ全体・教材・問題・最終提出付近のスクロール）、320px幅・縦横画面・文字拡大時の操作、エディターとの重なり防止と画面退出時の解除、12ページと問題の対応、50/75/90％の中央表示と100/125/150/200％拡大、ページ移動・最小化・再読み込み時のコード/回答保持、マウス・タッチ・キーボードでの移動とサイズ変更、画面サイズ変更、HTML/CSS/JavaScriptの実行、クラウド保存のドキュメントとmerge指定、クラウド読込とローカル下書きの競合、見本コードの上書き確認、7コース・先生用管理画面・通常Web教材の表示。

画面確認用スクリーンショットは `/tmp/learning-studio-{pdf,desktop,floating,mobile}.png` に出力します。スマートフォンの確認はChromiumのモバイル・タッチエミュレーションです。実機のソフトウェアキーボードの挙動、および本番Firebaseの認証・Firestoreルールはこのテストの検証対象に含みません。

固定バーの検証画面は `/tmp/learning-studio-navigation-{desktop,mobile}.png` に出力します。

順次学習のテストでは、新規生徒の第1ページ開始、未解放ページの直接選択拒否、1ページ目の読了と、第2〜10ページの必須だけの完了による順次解放、第11ページの未回答提出拒否と提出後の第12ページ解放を、PC・モバイルそれぞれで実際に操作します。旧回答の併合、新しいログイン環境でのFirebaseデータからの位置・解放復元、先生による進度調整と古い端末下書きへの優先、通信失敗・履歴取得前の保存抑止も検証します。保存先は本番ではなくテスト用のメモリ内Firestoreです。

順次学習の画面は `/tmp/learning-studio-guided-{locks,test-desktop,test-mobile,zoom-desktop,zoom-mobile}.png` に出力します。従来の任意ページ移動の回帰テストには、学習済み生徒の履歴または先生プレビューのデータを使用し、新規生徒のロック検証とは分けています。

一体型ヘッダーは、共通部分と教材操作部分の親子関係、指定色、PC・スマートフォンの高さ、320px幅・横向き・長い名前・キーボード表示相当の画面縮小、本文・PDF・問題のスクロール、エディターの上端制限を検証します。生徒・先生の両方でログアウト→ログインを実際のフォームから操作し、他のコース・管理画面で教材操作が残らないことも確認します。認証処理はテスト用Firebase SDKで代替しています。

完成画面は `/tmp/learning-studio-unified-header-{desktop,mobile,editor,mobile-practice}.png` に出力します。PC・スマートフォンのキャプチャはテスト用生徒名とテスト用進捗を使っています。

1ページ目の導入テストでは、PC・スマートフォンの両方で、クイズとミッション数を表示しないこと、先生に聞く案内、「使い方を確認して次へ」と固定バーの「次へ」による読了・ページ移動、旧設問の回答・判定とコードの保持、再ログインでの読了復元を確認します。2ページ目以降の設問を使って従来の回答保持・保存テストを継続しています。導入ページの画面は `/tmp/learning-studio-page1-introduction-{desktop,mobile}.png` に出力します。

キャッシュ更新テストは、通常の通信代替テストとは別に、Playwrightのリクエストルーティングを無効にしてChromiumのHTTPキャッシュを有効にします。テスト用サーバーで旧表記と未バージョン化のモジュールを1年間キャッシュ可能として読み込み、配信内容を新しいリリースへ切り替えます。同じブラウザで再読み込みし、新しい4段階が表示され、旧モジュールのレスポンス自体はキャッシュに残っていることを確認します。コード・CSS・学習位置・localStorage/sessionStorageの保持、PDFと画像の更新URLも検証します。認証・Firestoreの境界だけをローカルのテスト用SDKへ置き換え、本番Firebaseへは接続しません。

キャッシュ更新後のスマートフォン画面は `/tmp/learning-studio-mobile-cache-update.png` に出力します。

先生の教材編集では、PC・スマートフォンの両方でPDF本文・右側問題の変更、Firestoreへの保存、生徒側への反映、旧回答の保持、問題変更時の回答キー分離を検証します。JSON読み込み・書き出し、10問未満の拒否、同時編集の上書き防止、保存失敗時の下書き保持、最終提出12問の再読込復元・提出も検証します。

編集画面は `/tmp/learning-studio-author-dialog-{desktop,mobile}.png`、編集PDFは `/tmp/learning-studio-teacher-edited-{desktop,mobile}.pdf` に出力します。PDFの変更ページは画像として格納し、日本語の描画を維持します。原本PDFは変更しません。本番Firestoreへの書き込み・権限はネットワーク制限のため未検証です。

先生向けヘルプは、PCとスマートフォン（320px・375px・横向き幅）で右上ボタンの操作領域、ログアウトとの重なり・横はみ出し、画面内のヘルプ表示、目次の移動、「教材に戻る」・Esc・ブラウザの戻る操作、元の学習ページと編集中コード保持、ログアウト後の表示を確認します。手順書の画面は `/tmp/learning-studio-help-{desktop,mobile}.png` に出力します。


教材とチェックの対応は、PC・スマートフォンで第2〜12ページすべての新本文を実際に画像生成し、教材枠の項目と現在の問題の対応、先生による問題変更後の連動を確認します。第4・6・9・11ページの画面は `/tmp/learning-studio-aligned-{ページ番号}-{desktop,mobile}.png` に出力します。既存の先生編集テストでは全12ページのPDF生成も実行します。


Web開発コース①は、各レベル6教材・全30教材の見本をPC・スマートフォンで実際に操作します（計60パターン）。星集めの目標・リセット、宝探し、じゃんけん3分岐、クイズの二重回答防止、数当ての入力検証、タイマー終了、もぐら1匹1点、移動・壁・期限、最高得点・テーマ・版表示を検証します。タイマーはプレビュー内の現在時刻だけを進め、実際の終了処理を実行します。

ロードマップの3コース×5レベル、全30教材の非公開登録・再登録時の既存編集保持・意図した一括公開・選択問題の除外・登録失敗からの再試行・生徒の受講権限・非公開教材の一覧非表示も確認します。生徒によるコード保存・確認問題提出・作品のHTMLダウンロードを行い、出力した単独HTMLを別ページで実行し、最高得点が再読み込み後も残ることを確かめます。本番Firestoreには書き込みません。

画面は `/tmp/web-course-level{1〜5}-{desktop,mobile}.png` と `/tmp/web-course-roadmap-{desktop,mobile}.png` に出力します。教材の目安時間60〜90分は授業設計上の想定で、実際の生徒の所要時間を測定したものではありません。


図解教材は全30教材×5ページをPC・スマホで操作し、画像の実読込、ページとチェックの対応、図の拡大と横はみ出しを検証します。SVG60点は文字の領域を計測し、画像の外で切れていないことも確認します。各レベルの変更例を実際にコードへ適用し、説明した動作になることを試します。

新しいフローティングエディターではマウス・タッチでの移動、サイズ変更、最小化、ページ移動、ヘルプ往復でコードと実行中の得点が保たれること、320px・横向き・キーボード相当の縮小画面でヘッダーを覆わないことを検証します。印刷では画像を含む5ページをPDFにし、現在の先生の問題文が含まれることも確認します。

教材の画面は `/tmp/illustrated-web-level{1〜5}-{desktop,mobile}.png`、エディターは `/tmp/illustrated-web-floating-{desktop,mobile}.png`、印刷見本は `/tmp/illustrated-web-workbook.pdf` に出力します。スマートフォンはChromiumのエミュレーションで、実機の印刷ダイアログとソフトウェアキーボードは対象外です。
