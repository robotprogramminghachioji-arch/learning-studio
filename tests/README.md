# ブラウザ回帰テスト

Node.js 20以上とChromiumを使用します。アプリ自体にはnpm依存もビルドも不要です。npm依存はテスト専用です。

```sh
npm ci
# Chromiumが未導入の場合
npx playwright install chromium
npm test
```

Linuxでは `/usr/bin/chromium` があれば使用し、それ以外ではPlaywrightのChromiumを使用します。別の実行ファイルを使う場合は `CHROMIUM_PATH` で指定できます。現在のクラウド環境でnpmキャッシュに書き込めない場合は `npm --cache /tmp/learning-studio-npm-cache ci` を使えます。

テストは一時的なHTTPサーバーを起動し、実際の `index.html`、アプリのJavaScript/CSS、教材画像、sandbox付きプレビューをChromiumで操作します。Firebase SDKの通信境界のみを代替し、ログイン済み生徒・先生と保存成功・失敗・応答遅延を再現します。本番Firebaseへの書き込みやアカウント作成は行いません。

確認項目：ページ送りの画面上部固定（ページ全体・教材・問題・最終提出付近のスクロール）、320px幅・縦横画面・文字拡大時の操作、エディターとの重なり防止と画面退出時の解除、12ページと問題の対応、50/75/90％の中央表示と100/125/150/200％拡大、ページ移動・最小化・再読み込み時のコード/回答保持、マウス・タッチ・キーボードでの移動とサイズ変更、画面サイズ変更、HTML/CSS/JavaScriptの実行、クラウド保存のドキュメントとmerge指定、クラウド読込とローカル下書きの競合、見本コードの上書き確認、7コース・先生用管理画面・通常Web教材の表示。

画面確認用スクリーンショットは `/tmp/learning-studio-{pdf,desktop,floating,mobile}.png` に出力します。スマートフォンの確認はChromiumのモバイル・タッチエミュレーションです。実機のソフトウェアキーボードの挙動、および本番Firebaseの認証・Firestoreルールはこのテストの検証対象に含みません。

固定バーの検証画面は `/tmp/learning-studio-navigation-{desktop,mobile}.png` に出力します。

順次学習のテストでは、新規生徒の第1ページ開始、未解放ページの直接選択拒否、1ページ目の読了と、第2〜10ページの必須だけの完了による順次解放、第11ページの未回答提出拒否と提出後の第12ページ解放を、PC・モバイルそれぞれで実際に操作します。旧回答の併合、新しいログイン環境でのFirebaseデータからの位置・解放復元、先生による進度調整と古い端末下書きへの優先、通信失敗・履歴取得前の保存抑止も検証します。保存先は本番ではなくテスト用のメモリ内Firestoreです。

順次学習の画面は `/tmp/learning-studio-guided-{locks,test-desktop,test-mobile,zoom-desktop,zoom-mobile}.png` に出力します。従来の任意ページ移動の回帰テストには、学習済み生徒の履歴または先生プレビューのデータを使用し、新規生徒のロック検証とは分けています。

一体型ヘッダーは、共通部分と教材操作部分の親子関係、指定色、PC・スマートフォンの高さ、320px幅・横向き・長い名前・キーボード表示相当の画面縮小、本文・PDF・問題のスクロール、エディターの上端制限を検証します。生徒・先生の両方でログアウト→ログインを実際のフォームから操作し、他のコース・管理画面で教材操作が残らないことも確認します。認証処理はテスト用Firebase SDKで代替しています。

完成画面は `/tmp/learning-studio-unified-header-{desktop,mobile,editor,mobile-practice}.png` に出力します。PC・スマートフォンのキャプチャはテスト用生徒名とテスト用進捗を使っています。

1ページ目の導入テストでは、PC・スマートフォンの両方で、クイズとミッション数を表示しないこと、先生に聞く案内、「使い方を確認して次へ」と固定バーの「次へ」による読了・ページ移動、旧設問の回答・判定とコードの保持、再ログインでの読了復元を確認します。2ページ目以降の設問を使って従来の回答保持・保存テストを継続しています。導入ページの画面は `/tmp/learning-studio-page1-introduction-{desktop,mobile}.png` に出力します。
