# HTML入門レベル1の教材編集

先生でログインし、Web開発レベル1の教材内の「教材本文・問題・最終提出を編集」を開きます。ページごとにPDFタイトル・本文、右側の説明、必須／任意の問題、選択肢・正解、ヒント、見本コードを編集できます。導入の4段階の説明も編集できます。

「編集ページをプレビュー」で確認後、「生徒に反映して保存」を押すと既存の `lessons/{lessonId}` に教材データを保存します。生徒が教材を開き直すと反映します。同時編集による上書きを検知した場合は保存しません。下書きは端末内に残ります。既存の先生権限での教材書き込みを使用し、Firestoreルールは変更しません。

PDF本文を編集したページは、日本語フォントを使用した文字中心のレイアウトで生成します。元の図版レイアウトを直接編集する機能ではありません。未編集ページは元のPDF・画像を使います。PDF作成ボタンで全12ページのPDFをダウンロードできます。変更ページはプレビューと同一の画像をPDFへ配置するため、文字のコピー・検索はできません。編集用の本文はJSONに保持します。本文が収まらない場合や未対応文字は保存前に案内します。

## Codexとの共同編集

共通の原稿は `assets/html-level1-workbook.json` です。CodexはこのJSONを編集して `npm run version:assets` を実行します。`workbook-defaults.js` は自動生成のため直接編集しません。このコマンドは既存の生成データと比較し、問題変更時の回答キーの版も自動更新します。生成データを削除して作り直さず、JSONと生成ファイルを一緒にコミットしてください。

先生がクラウド保存した教材はリポジトリ既定教材より優先されます。現在の教材を「JSONを書き出す」で書き出し、Codexで編集したJSONを先生画面の「JSONを読み込む」で読み込み、確認・保存すると確実に同期できます。クラウド教材をGit更新で自動上書きしません。

ページID・順序は全12ページ固定です。問題IDは維持してください。問題の内容変更時は保存処理が回答キーの版を分け、以前の回答を削除せず残します。既に完了したページの進捗も維持します。再学習が必要な場合は既存の先生用進度調整を使います。

## 最終提出

第11ページの確認テストとは別に、レッスン全体の最終提出を12問用意しています。HTMLの役割、文書構造、見出し・文章・リスト・リンク・画像、保存と表示確認を問います。先生は10〜30問の範囲で編集できます。第11ページ提出後に利用可能です。全問必須で、先生が採点します。

提出データは従来の `submissions` の形式を維持し、問題文と回答を文字列に含めます。以前の提出・採点履歴は削除しません。回答中の原稿は同じ端末に保存され、送信失敗時にも残ります。端末の共有時は利用者のログインを切り替えてください。

## 依存素材

PDF生成には同梱の pdf-lib 1.17.1 と @pdf-lib/fontkit 1.1.1（MIT）を使用します。日本語フォントはNoto CJK配布のNoto Sans JP Regular（OFL）です。配布元のライセンスは `assets/vendor/` と `assets/fonts/OFL.txt` に同梱しています。実行時に外部PDF生成サービスへ送信しません。

フォント配布元: https://github.com/notofonts/noto-cjk/blob/main/Sans/SubsetOTF/JP/NotoSansJP-Regular.otf
