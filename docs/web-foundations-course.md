# Web開発コース①：ゲームで学ぶWeb制作の基礎

全30教材・約30〜45時間（1教材60〜90分）

## 受講の進め方

各レベル6教材です。1教材60〜90分を目安に、読む→作る→動作確認→振り返りの順で進めます。例：体験5分、説明15分、基本制作25分、検証10分、改造・振り返り15分。授業時間に合わせて2回に分けられます。時間だけでなく、操作結果と理由を説明できることを基準にします。

基本課題、予想と実際の比較、不具合を調べる課題、追加の改造、記述式の確認問題を用意しています。確認問題の対象は同じ教材の本文・実習で説明しています。各教材には実行できるHTML・CSS・JavaScriptの見本があり、外部素材や外部通信は不要です。

## 教材一覧

### LEVEL1：はじめてのWebページとゲーム

HTMLの基本と保存を学び、目標とやり直しのある星集めを作る。 目安：6〜9時間。

- **第1回｜まずは星集めゲームを動かそう**：HTML・CSS・JavaScriptの場所を知り、ゲームの文字を変えて実行できる。
- **第2回｜自己紹介とゲームをつなごう**：見出し・文章・リスト・リンクを使い、遊び方付きのゲームページを作れる。
- **第3回｜クリア目標を変えてみよう**：用意されたJavaScriptの数字を変更し、目標で終わるゲームを調整できる。
- **第4回｜保存して友だちに遊んでもらおう**：やり直しを試し、作品ファイルの保存とブラウザでの確認ができる。
- **第5回｜画像でゲームの世界を伝えよう**：imgのsrcとaltを使い、画像と説明を対応させられる。
- **第6回｜自己紹介ゲームをミニ発表しよう**：HTML・画像・ルール・保存を組み合わせ、作った作品を説明できる。

### LEVEL2：CSSでゲーム画面を作る

色・余白・配置・状態の見た目・スマホ対応を学ぶ。 目安：6〜9時間。

- **第1回｜CSSで星集めをデザインしよう**：CSSのセレクターと宣言を使い、文字・色・余白を変更できる。
- **第2回｜宝探しの箱を並べよう**：クラスとCSS Gridを使い、複数のボタンを並べられる。
- **第3回｜発見した箱の見た目を変えよう**：クラスの追加・削除とリセットによる見た目の変化を理解できる。
- **第4回｜スマホでも遊べる宝探しを完成しよう**：レスポンシブ表示を理解し、狭い画面でも遊べる作品にできる。
- **第5回｜Flexboxで遊び方パネルを作ろう**：FlexboxとGridを使い分け、操作と説明を整理できる。
- **第6回｜見やすく操作しやすいゲームにしよう**：フォーカス・文字情報・動きへの配慮を使い、アクセシブルな画面へ改善できる。

### LEVEL3：JavaScriptでルールを作る

変数・条件分岐・関数・乱数・配列を使ってルールを実装する。 目安：6〜9時間。

- **第1回｜変数と計算で得点のルールを作ろう**：変数・定数・計算・比較を使い、得点と終了条件を変更できる。
- **第2回｜条件分岐と乱数でじゃんけんを作ろう**：乱数と条件分岐で、勝ち・負け・あいこを判定できる。
- **第3回｜関数でじゃんけんの処理を整理しよう**：引数と戻り値を持つ関数を使い、判定・表示・記録を分けられる。
- **第4回｜配列を使って3問クイズを作ろう**：配列とオブジェクトで問題を管理し、順番と得点を処理できる。
- **第5回｜入力チェック付き数当てを作ろう**：フォームの入力を検証し、正しくない値を処理しないゲームを作れる。
- **第6回｜対戦履歴を配列で表示しよう**：配列への追加・削除とDOM生成で、直近の対戦を表示できる。

### LEVEL4：時間と動きのあるゲーム

タイマー・繰り返し・座標・当たり判定・難易度を扱う。 目安：6〜9時間。

- **第1回｜タイマーで制限時間を付けよう**：時間を計測してゲームを終了し、タイマーの重複を防げる。
- **第2回｜もぐらたたきを作ろう**：複数の対象を繰り返し作り、ランダムな位置の出現と得点を処理できる。
- **第3回｜矢印とタッチで宝を集めよう**：座標・境界・当たり判定を使い、PCとスマホで操作できる。
- **第4回｜難易度を選べるゲームに仕上げよう**：入力値を使って難易度を変更し、不具合を順序立てて調べられる。
- **第5回｜障害物をよけて宝へ進もう**：移動先を先に検証し、壁に入らない当たり判定を実装できる。
- **第6回｜制限時間付きアイテム集めを完成しよう**：移動・当たり判定・タイマーを組み合わせ、終了と再開始を管理できる。

### LEVEL5：オリジナル作品を完成・公開

企画からコード整理・端末保存・テスト・公開・改善まで取り組む。 目安：6〜9時間。

- **第1回｜オリジナルゲームの企画を作ろう**：利用者・ルール・完成条件を決め、制作する範囲を絞れる。
- **第2回｜処理を整理して最高得点を保存しよう**：関数を整理し、端末保存の成功・失敗を分けて扱える。
- **第3回｜PC・スマホで作品をテストしよう**：テスト項目を作って実行し、改善前後の結果を説明できる。
- **第4回｜作品紹介サイトを公開しよう**：紹介・遊び方付き作品を公開し、URLから再確認して改善できる。
- **第5回｜感想をもとにテーマ切り替えを追加しよう**：公開後の意見から小さな改善を選び、設定と保存を追加できる。
- **第6回｜変更履歴を残して作品を育てよう**：変更内容・テスト結果・公開手順を記録し、次の学習目標を説明できる。

## 先生による登録・公開

1. 先生でログインし、ホームのWeb開発コース①で各レベルの見本を確認します。既存のHTML入門は「以前の教材・補助教材」に残ります。
2. 「先生用管理」→「教材・問題管理」→「コース① 30教材を非公開で登録」を押します。既存IDがあればその教材と採点基準を保持し、未登録分だけを登録します。
3. 教材を必要に応じて編集します。各教材の文章、課題、確認問題、HTML/CSS/JavaScript初期コードを通常の編集画面で変更できます。
4. 内容確認後、「確認済みのコース①をまとめて公開」で登録済みの記述式教材を公開できます。個別に「内容確認済み・公開する」で公開することもできます。選択問題に変更した教材は個別の編集・保存で公開してください。
5. Web開発の受講権限がある生徒が再ログインすると公開教材を受講できます。非公開教材と先生用見本は生徒の受講一覧には出ません。
6. 生徒は「学習内容を保存」で作品を保存し、確認問題へ操作結果と考えを書いて提出します。先生は「提出・採点・CSV」で採点し、「Web制作の学習履歴」の「保存コードを見る」で作品コードを確認できます。

登録や公開に失敗した場合は途中まで保存済みの可能性があります。画面を開き直して状態を確認し、未処理分を再実行してください。登録を繰り返しても既存原稿を上書きしません。登録済みの教材を削除すると生徒一覧から消え、先生側には登録前の見本が再表示されます。

## 作品の保存と公開

新教材の「HTMLを保存」はCSSとJavaScriptを含む単独の `index.html` を出力します。素材・通信を使わないため、先生とブラウザで開いて作品を確認できます。GitHub Pagesでの初回公開、ブランチとPRでの更新、Actionsの確認をLEVEL5で扱います。公開には利用者自身のGitHub権限と先生・保護者の運用方針が必要です。

ゲームの最高得点・テーマ保存はブラウザの `localStorage` を使います。安全なプレビューの中では使えないため、例外を処理し今回のゲーム内だけで状態を持ちます。公開サイトの同じブラウザで再読み込みして永続化を確認します。学習コードのクラウド保存とは別の仕組みです。

## コース①〜③の構成

ホームの「コース①〜③の構成を見る」から学習ロードマップを閲覧できます。各コースはLEVEL1〜5です。①の修了だけで仕事に必要な範囲をすべて扱うわけではありません。

### コース①：ゲームで学ぶWeb制作の基礎

教材あり。HTML・CSS・JavaScriptで、ゲームと紹介サイトを作り、PC・スマホで確かめて公開できる。

- LEVEL1：はじめてのWebページとゲーム — 星集めゲームと自己紹介ページ
- LEVEL2：CSSでゲーム画面を作る — スマホでも遊べる宝探しゲーム
- LEVEL3：JavaScriptでルールを作る — じゃんけんゲーム・3問クイズ
- LEVEL4：時間と動きのあるゲーム — もぐらたたき・アイテム集め
- LEVEL5：オリジナル作品を完成・公開 — オリジナルゲームと作品紹介サイト

### コース②：実用的なWebアプリ開発

今後の学習予定。画面・外部データ・ログイン・サーバーを組み合わせ、小規模なWebサービスを作る。

- LEVEL1：JavaScriptを使いこなす — オブジェクト・配列操作・入力検証・例外処理・モジュールで学習管理アプリを作る。
- LEVEL2：外部データを使う — HTTP・JSON・非同期処理・APIと、通信中・失敗時の表示を学ぶ。
- LEVEL3：コンポーネントで画面を作る — TypeScript・React・状態管理で複数画面の学習アプリを作る。
- LEVEL4：ログインとデータベース — 認証・ユーザーごとの権限・データ保存を学ぶ。
- LEVEL5：フルスタック開発入門 — サーバー・API・秘密情報管理を学び、サーバーで得点を検証するランキング付きゲームを公開する。

### コース③：開発者としての実践

今後の学習予定。要件整理・安全性・チーム開発・公開後の運用を学び、実際の利用者と改善を続ける。

- LEVEL1：設計とデータ管理 — 利用者の要望から要件・データベース・APIを設計する。
- LEVEL2：品質と安全性 — 自動テスト・アクセシビリティ・入力検証・認証認可で品質を高める。
- LEVEL3：チーム開発 — Gitブランチ・PR・レビュー・Issueで共同制作する。
- LEVEL4：公開後の運用 — CI/CD・ログ・監視・バックアップ・性能・費用を確認する。
- LEVEL5：卒業制作 — 企画・開発・公開・利用者テスト・改善を行い、ポートフォリオにまとめる。

## 原稿の更新

原稿は `assets/web-course.json` です。編集後に `npm run version:assets` で `assets/web-course-data.js` と読み込みURLを生成します。生成モジュールを直接編集しません。既存教材IDは維持してください。先生がFirestoreに登録・編集した教材はそちらを優先し、Git更新で自動上書きしません。原稿更新を登録済み教材に取り入れる場合は、先生の編集画面で必要な部分を反映してください。

`config.js` とFirestoreルールは変更せず、既存の `lessons`・`answer_keys`・`web_workspaces`・`submissions` を使用します。受講権限のキーは従来と同じ `web` です。
