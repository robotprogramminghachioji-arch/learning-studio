1. 編集画面の選び方

ログイン画面の「区分」で「先生」を選び、先生のメールアドレスとパスワードでログインします。登録済みの先生権限が必要です。

  • 教材の基本情報・公開設定・通常の確認問題：「先生用管理」→「教材・問題管理」を開きます。
  • Web開発レベル1の12ページ教材・ページ別問題・最終提出：ホームの「Web開発」→「Lv.1」→HTML入門の教材を開き、「教材本文・問題・最終提出を編集」を押します。

HTML入門のページ別問題は通常の「確認問題」と別です。編集したい場所に合う画面を選んでください。

Web開発コース①の教材を登録・公開する

ホームのWeb開発カードから「コース①〜③の構成を見る」で全体像を確認できます。各コースはLEVEL1〜5で、今回は①の各6教材・全30教材を用意しています。②・③は今後の学習予定です。①は1教材60〜90分、合計30〜45時間が目安です。

  1. 先生の教材プレビューで各レベルの見本を確認します。最初の教材からゲームを動かせます。
  2. 「先生用管理」→「教材・問題管理」→「コース① 30教材を非公開で登録」を押します。登録済みの教材と採点基準は上書きしません。
  3. 必要に応じて各教材の「編集」で文章・問題・初期コードを変更し、保存します。
  4. 内容を確認してから「確認済みのコース①をまとめて公開」を押します。個別の公開もできます。選択問題に変更した教材は、個別の編集画面から公開してください。
  5. 生徒は再ログインすると、受講権限のあるWeb開発の公開教材を開けます。以前のHTML入門は「以前の教材・補助教材」に残ります。

生徒は作品コードを保存し、実際の結果と考えを確認問題へ記述して提出します。先生は「提出・採点・CSV」で採点し、「Web制作の学習履歴」の「保存コードを見る」で作品を確認できます。

ゲームの最高得点を端末に残す動作は、安全なプレビューでは制限されます。ゲームはそのまま試せますが、記録の再読み込みは公開後のサイトで確認します。学習コードのクラウド保存とは別です。

2. 通常教材を作成・編集・公開する

  1. 教材一覧で既存教材の「編集」、または「新規作成」を押します。
  2. コース・レベル・並び順（小さい順）を指定し、タイトル、到達目標、学習解説、実践課題、確認問題を入力します。
  3. 選択問題にする場合は選択肢を4つすべて入力し、「正解の番号」を1〜4から選びます。記述式にする場合は選択肢をすべて空欄にします。一部だけの入力では保存できません。
  4. 「正解・採点基準（先生専用）」と「先生用ヒント（非公開）」を入力します。公開した4択問題では、正解番号と採点基準の先頭500文字が自動採点用に生徒のブラウザへ送られます。採点基準に機密情報を入れないでください。
  5. 必要に応じて画像パス・画像の説明・YouTube動画URL・PDF教材パス・Web演習のHTML/CSS/JavaScript初期コードを設定します。画像は同じサイトの相対パス（例：images/scratch-editor.png）または同一オリジンのHTTPS URL。PDFは assets/pdfs/ 内の半角英数字ファイル名（例：assets/pdfs/html_lesson01.pdf）を指定します。ファイル自体は別途GitHubへ配置してください。この画面にアップロード機能はありません。
  6. 確認前は「内容確認済み・公開する」を外して「保存」。成功メッセージ「教材と先生専用の正解を保存しました。」を確認します。ホームの教材プレビューから表示を確認してください。
  7. 公開する際は再び「編集」を開き、「内容確認済み・公開する」にチェックして「保存」します。生徒に教材を開き直してもらい、表示・問題を確認します。非公開に戻す場合はチェックを外して保存します。

「閉じる」は保存ではありません。通常教材の入力には、専用編集画面のような端末原稿の復元機能はありません。

「削除」は確認後に教材と正解データを削除します。過去の提出履歴は残ります。「初期教材30件を登録」「HTML第1回教材を登録」は初期教材を追加する操作です。日常の変更には既存教材の「編集」を使ってください。

3. HTML入門レベル1の本文・問題を編集する

  1. 教材内の「教材本文・問題・最終提出を編集」を開き、「編集するページ」で対象ページを選びます。全12ページの構成と順序は固定です。
  2. 「学習テーマ」「右側の説明」「PDFタイトル」「PDF本文」を編集します。1ページ目は導入説明専用で、導入の見出し・本文や4段階の学習の流れを編集できます。問題は追加できません。
  3. 2〜12ページの問題は「形式」（選択問題・記述問題・操作確認・コード課題）と問題文を設定します。「問題を追加」「上へ」「下へ」「この問題を外す」で構成を調整できます。1ページ30項目以内、各ページに必須項目を1つ以上残してください。
  4. 選択問題は「選択肢（1行に1つ）」に2〜6個を入力し、「正解番号（1から）」と解説を設定します。記述問題は記述ヒント、コード課題は用意されたコード判定とコードヒントを設定します。「必須」を外すと任意問題になります。第11ページは選択・記述式で10問以上、すべて必須です。
  5. 必要に応じて「エディターヒント」「見本HTML」を編集します。「レッスン全体の最終提出（10問以上）」を開くと、別枠の最終提出を10〜30問で編集できます。問題文と回答形式（記述／コード）を設定し、追加・削除します。最終提出は第11ページのテスト提出後に利用でき、全問必須・先生採点です。
  6. 「編集ページをプレビュー」で本文と右側の問題を確認します。「編集内容でPDFを作成」では全12ページをダウンロードできます。どちらもクラウドへの保存操作ではありません。
  7. 「生徒に反映して保存」を押し、「教材本文・問題・最終提出を保存しました。生徒の次回教材表示から反映します。」を確認します。生徒には教材を開き直してもらいます。教材の公開・非公開は、通常教材の編集画面で設定します。

PDF本文を変更したページは、日本語フォントを使った文字中心のレイアウトで再生成されます。元の図版配置を直接編集する機能ではありません。原本と未編集ページは残ります。変更ページを含む出力PDFの変更部分は画像形式で、文字の検索・コピーはできません。

問題を変更して保存すると回答キーの版を分け、以前の回答を残します。完了済みの進度も維持します。再学習が必要なら、教材画面の「先生用：生徒の学習進度を調整」で対象生徒の進度を読み込み、学習済みの範囲を変更して保存してください。回答とコードは残ります。

4. JSONでバックアップ・復元・共同編集する

  1. HTML入門専用の編集画面で、変更前や作業の区切りに「JSONを書き出す」を押して原稿を保管します。書き出し時も内容の検証があります。
  2. 同じ端末・ブラウザ・先生アカウントで作業を再開する際は、「端末の編集中原稿を復元」を押し、プレビューしてから保存します。入力は端末にも一時保存されますが、ブラウザのデータ削除や別端末への移動には備えられません。
  3. ファイルから戻す場合は「JSONを読み込む」で800KB以内の教材JSONを選びます。現在の編集原稿が置き換わるため、先に必要な原稿を書き出してください。読み込み後は内容を確認し、「生徒に反映して保存」を押します。
  4. Codexと共同編集する場合は現在のJSONを渡し、編集後のJSONを読み込んで確認・保存します。クラウドに保存した教材がGitHubの既定教材より優先されるため、GitHub側の更新だけではクラウド教材は置き換わりません。ページID・順序と既存問題IDは維持してください。

5. 保存できない・変更が見えないとき

  • 入力エラー：画面の案内に従い、必須項目・問題数・正解番号・本文の長さを確認します。PDFに本文が収まらない場合は短くし、未対応文字も修正します。
  • 通信・権限エラー：成功メッセージが出ていなければ保存完了とは扱わず、通信状態と先生権限を確認します。HTML入門は原稿をJSONに書き出して保管し、再試行してください。
  • 「別の編集が保存されています」：自分の原稿をJSONに書き出し、教材を開き直して最新の内容と比較します。必要な変更を合わせてから保存し直してください。
  • 生徒に反映されない：保存成功と公開設定を確認し、生徒が教材を開き直したか確認します。GitHubによるアプリ更新時は公開完了後にブラウザを再読み込みしてください。
  • スマートフォン：編集画面を縦にスクロールして各項目と保存ボタンへ移動します。長文や問題数の多い教材はPCで編集すると確認しやすくなります。

この手順書はアプリの教材管理・HTML入門編集機能に対応しています。
